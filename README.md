#  COVID-19 Global Data Analysis with BigQuery & Power BI

## Project Overview

This project explores global COVID-19 data using **Google BigQuery**, **SQL**, and **Power BI**.

The primary objective was to explore data using SQL queries in BigQuery and transform the results into interactive Power BI dashboards. The analysis focuses on infection rates, death rates, vaccination progress, and geographical trends across countries and continents.

This project demonstrates skills in:

- SQL Data Exploration
- Google BigQuery
- Data Analysis
- Data Visualization
- Dashboard Development
- Business Intelligence

##  Dataset

The project uses publicly available COVID-19 data (https://ourworldindata.org/covid-deaths) containing:

- Country and continent information
- Population statistics
- Total and new COVID-19 cases
- Total and new COVID-19 deaths
- Vaccination records
- Reporting dates

##  SQL Data Exploration

The SQL analysis focused on answering key questions about the pandemic:

### Mortality Analysis
- Comparison between total cases and total deaths.
- Calculation of death percentages by location.
- Identification of countries with the highest death counts.
- Analysis of total COVID-19 deaths by continent.

### Infection Analysis
- Identification of countries with the highest infection rates relative to population.
- Daily tracking of infection rates by country.
- Comparison of infection growth trends across different regions.

### Vaccination Analysis
- Calculation of cumulative vaccination counts.
- Tracking vaccination progress over time.
- Estimation of the percentage of the population vaccinated.

### Global Trends
- Daily aggregation of global cases and deaths.
- Monitoring changes in global mortality rates throughout the pandemic.

*SQL scripts used for the analysis are available in the `/sql` folder.*

##  Power BI Dashboard

The Power BI dashboard was designed to communicate insights discovered during the SQL exploration phase.

### Dashboard Features

- KPI cards displaying:
  - Total Cases

  - Death Percentage

- Continental comparison of total deaths.

- Interactive world map showing infection rates by country.

- Time-series visualizations displaying infection rate evolution.

##  Key Insights

### 1. Europe recorded the highest cumulative death count

Among all continents, Europe reported the highest total number of COVID-19 deaths, followed by North America and South America. This indicates the severe impact of the pandemic across European countries during the study period.

### 2. Infection severity differed greatly between countries

Countries with similar population sizes often experienced very different infection rates, suggesting that factors beyond population size influenced the spread of the virus.

### 3. Some countries experienced much faster infection growth

The infection rate evolution revealed distinct waves of contagion. Several countries showed rapid growth periods followed by slower increases, reflecting the changing dynamics of the pandemic over time.

### 4. Global case growth significantly accelerated during late 2020

Time-series analysis showed a noticeable rise in infection rates across multiple countries between the end of 2020 and the beginning of 2021, corresponding to major pandemic waves.

### 5. Vaccination campaigns gained momentum in early 2021

Vaccination data showed a strong increase in the cumulative number of vaccinated individuals across many countries, highlighting the large-scale deployment of vaccination programs.

### 6. High case counts did not always imply high mortality rates

Some countries recorded high infection counts while maintaining relatively lower death percentages, emphasizing the importance of analyzing both infection and mortality metrics together.

### 7. Geographic patterns revealed regional hotspots

The world map visualization highlighted significant differences in infection rates between countries, making it easier to identify regions that were particularly affected during the pandemic.
